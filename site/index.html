How it works

Three steps, no window to switch to.

omnihear sits in the background. You don't open it to dictate; you hold a key.

Hold your hotkey

Right Ctrl by default, or any key or combo like ctrl_l+space. A small waveform shows you're recording.

Speak normally

Audio stays in memory on your machine. Silence is trimmed and the level normalized before transcription.

Let go

faster-whisper transcribes it locally and the text is typed into the focused field, in order, even if you dictate faster than it transcribes.

Features

Dictation that respects the machine it runs on.

Everything below runs locally. There is no omnihear server.

Private by default

Whisper runs on your CPU or GPU. No account, no upload, works offline once a model is downloaded.

Works in every app

Types into the focused field like a keyboard would: IDEs, browsers, Slack, email, terminals.

Wayland, natively

Built-in virtual keyboard for GNOME, KDE and wlroots. No ydotool daemon to babysit. omnihear --doctor checks your setup.

History dashboard

A local web dashboard with searchable history, words-per-day chart, latency and resource stats, and every setting.

Voice commands

Turn them on to say "comma", "new line", or "scratch that" to erase the last dictation. Optional git commands in X11 terminals.

Learns your words beta

Common Brain picks up the names and jargon you correct often and nudges Whisper toward them next time.

Ask by voice beta

A second hotkey sends your question, plus relevant past dictations, to a local Ollama model and types the answer.

Light on resources

The model loads on first press and unloads after 10 idle minutes. Pick from tiny to large-v3-turbo, CPU int8 or CUDA.

100 languages

Every Whisper language, or auto-detect. English-only models are faster when that's all you need.

Why local

Same push-to-talk flow, without the cloud.

Cloud dictation apps are polished, but every word goes to a server. omnihear keeps the loop on your machine.

Install

Pick your platform.

The first hotkey press downloads the Whisper model once (about 150 MB for the default base.en).

Signed APT repository. Updates arrive with sudo apt upgrade. Needs Python 3.11+ (Ubuntu 24.04 or newer, Debian 12 or newer).

curl -fsSL https://dsb-03.github.io/omni-hear/pubkey.gpg | sudo gpg --dearmor -o /usr/share/keyrings/omnihear.gpg
echo "deb [signed-by=/usr/share/keyrings/omnihear.gpg] https://dsb-03.github.io/omni-hear/ stable main" \
  | sudo tee /etc/apt/sources.list.d/omnihear.list
sudo apt update && sudo apt install omnihear

On Wayland (the Ubuntu default), allow the hotkey to read your keyboard, then log out and back in. Typing works out of the box.

sudo usermod -aG input $USER

Then start it with your desktop session and check the setup:

systemctl --user enable --now omnihear
omnihear --doctor

Download omnihear-setup-*.exe from the latest release and run it. omnihear lives in the system tray, with Open Dashboard and Quit.

Download for Windows

The installer isn't code-signed yet, so SmartScreen will warn. Click More info then Run anyway.

Apple Silicon (M1 or later), macOS 11+. Download omnihear-*-arm64.dmg, open it, and drag Omnihear to Applications. It runs from the menu bar.

Download for macOS

On first launch, grant Microphone, Accessibility and Input Monitoring in System Settings › Privacy & Security. The dashboard has one-click links.

Dashboard: while omnihear runs, open http://127.0.0.1:4738 for history, stats and settings. It only listens on localhost.
FAQ

Questions

Does any audio or text leave my computer?

No. Recording, transcription and typing all happen locally. The internet is only used to install omnihear and download a Whisper model once. Anonymous usage pings exist but are off unless you opt in, and never include audio or text.

Does it work on Ubuntu with Wayland?

Yes. Ubuntu 24.04 and later, including releases without an X11 session. Hotkeys read your keyboard directly (one-time input group step) and typing uses a built-in virtual keyboard, so there's no ydotool or wtype to set up. It works on GNOME, KDE and wlroots compositors. Run omnihear --doctor if something's off.

How fast is it?

With the default base.en model on a modern laptop CPU, a short sentence usually types within a second of letting go. Larger models are more accurate and slower. With an NVIDIA GPU, set device = "cuda" for large-v3-turbo at interactive speed.

Which keyboard layouts are supported for typing?

On X11, Windows and macOS, any layout. On Wayland, the built-in typer assumes US QWERTY, so a few symbols can come out wrong on other layouts. Accented letters and emoji go through IBus (GNOME's default). Clipboard-paste typing for every layout is on the roadmap.

Can I change the hotkey?

Yes. Use any single key (F9, Right Alt, Pause, a letter) or a combo like ctrl_l+space, from the dashboard's Settings or ~/.config/omnihear/config.toml.

Is it free?

Yes, and the source is on GitHub.
